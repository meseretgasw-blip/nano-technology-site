# Nano Technology — Site

Static storefront for Nano Technology (Bole Medhanialem, Addis Ababa). Plain HTML/CSS/JS, deployed to Cloudflare Pages.

## Structure
- `index.html` — page markup
- `styles.css` — all styling
- `app.js` — product data + interactivity
- `_headers` — Cloudflare Pages cache/security headers
- `robots.txt`
